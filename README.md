# Motivation App

A simple web application that displays random motivational quotes to encourage users throughout the day.

## Features
- Generates a random motivational quote
- Updates the quote dynamically using JavaScript
- Clean and minimal user interface
- Built as part of my journey into software engineering

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was built to practice JavaScript fundamentals such as arrays, functions, and DOM manipulation while creating a simple interactive application.

## Future Improvements
- Add a larger quote database
- Allow users to add their own quotes
- Store quotes using localStorage
